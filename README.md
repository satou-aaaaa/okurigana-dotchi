# 送りがなどっち（okurigana-dotchi）

ことばの読みと文を見て、送りがなが正しい書き方（少ない・少い・少くない など）を当てる1日5問の学習ゲーム。正解したら「どの決まりでそう書く？」（通則1〜7）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/okurigana-dotchi/>

- 中身は、文化庁「送り仮名の付け方」（昭和48年内閣告示第2号・平成22年一部改正。<https://www.bunka.go.jp/kokugo_nihongo/sisaku/joho/joho/kijun/naikaku/okurikana/index.html>）の通則1〜7と付表に書いてあることだけです（2026-11-17 に読みました）。
- 答えは本則（基本の書き方）です。告示が「許容」として認める書き方（表わす・申込む など）は、まちがいの選び肢に入れていません。
- このゲームは送りがなを知る練習です。公式の情報の代わりではありません。決まりは文化庁のページで確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
